# 第三问总结：Pareto 多目标优化 + 多准则决策

> 代码：`code/nsga2.py`（非支配排序/NSGA-II）、`code/mcdm.py`（熵权/TOPSIS/灰色关联）、`run_q3.py`
> 目标函数：Q2 高斯过程代理模型（R、P、U 的预测值）

## 1. 优化模型

    min F(x) = (R(x), P(x), U(x))
    s.t. 0≤w≤0.3, 3≤r≤4.5, n∈{0,2,4,6,8,10}（混合变量）
         有效组合：无针肋(w=0,n=0) 或 有针肋(w≥0.1, n>0)
         —— 排除 w∈(0,0.1) 的数据外推区与 w>0,n=0 的无物理意义区

## 2. 求解与前沿

- **方法1：网格穷举 + 非支配排序**（精确前沿）
  候选 6386 个（w∈{0}∪[0.1,0.3]、r 步长 0.05、n 6 档）→ **Pareto 前沿 268 点**；
- **方法2：NSGA-II**（自实现，种群 200×600 代）
  前沿 198 点，**到网格前沿最短目标距离均值 0.00056**（≈0）→ 两法前沿一致，验证正确性；
  因本问题仅 3 变量、n 离散档少，以网格前沿为最终结果（更严格）。

## 3. 多准则决策（MCDM）

**熵权法**（数据驱动客观赋权，基于 Pareto 前沿决策矩阵）：
    w_R = 0.155，w_P = 0.366，w_U = 0.479
（Pareto 前沿上 U 的区分度最高→权重最大；R 变化带窄→权重最小）
> 注意：熵权-TOPSIS 的权重应从"待决策的决策矩阵"（Pareto 前沿）计算。
> 若误用 84 个训练样本算熵权，R 会因变化带窄而虚高（w_R=0.459），导致最优解偏移。

**决策结果（在 Pareto 前沿上）**：
| 方法 | 最优 (w, r, n) | C/关联度 |
|---|---|---|
| 熵权-TOPSIS（主） | **(0.215, 4.500, 4)** | C 最高 |
| 等权-TOPSIS（对比） | (0.220, 4.500, 4) | C 接近 |
| 熵权-灰色关联（对比） | (0.215, 4.500, 4) | 关联度最高 |

三种方法的最优解**完全一致**（r=4.5、n=4、w≈0.215~0.22）→ 决策结果稳健。

## 4. 综合最优设计方案

    w* = 0.215，r* = 4.500，n* = 4

GP 预测（均值 ± 标准差）：
- **R = 0.7414 ± 0.0001**
- **P = 0.0842 ± 0.0005**
- **U = 0.7722 ± 0.0004**

与附件2 数据对比：最近样本 #64 (w=0.2, r=4.5, n=4)：R=0.7422, P=0.0831, U=0.7740，
GP 预测与真实数据几乎重合 → 最优解合理、非外推、可信度高。

## 5. 决策准则合理性论证（论文 E 部分）

1. **为什么用熵权法**：权重由 84 组样本的信息熵客观确定，无需主观赋值；
   R 指标在样本中区分度最大（热阻优化空间最小但最受关注），故权重最高；
   熵权法避免人为偏好，是"数据驱动"的合理赋权。
2. **TOPSIS 的物理意义**：在 Pareto 前沿上选取"距理想点（三项指标均最优）
   最近、距负理想点最远"的方案，物理含义直观（最接近三目标同时最优的折中）。
3. **鲁棒性**：等权 TOPSIS 与灰色关联度给出 n=4、w≈0.22 的相近结论，
   说明最优方案对决策准则不敏感。

## 6. 结果与 Q1 的呼应

- 最优 n*=4 与 Q1 温度非均匀性最优排数一致（n≈4 时 U 最小）；
- 最优 w*≈0.215 接近 Q1 中 R/U 的 w≈0.2 最优区；
- r*=4.5（取上限）体现熵权/等权/灰色关联对 P、U 的偏好（高 r 使 P、U 更优，
  R 略有牺牲），三种方法一致。
