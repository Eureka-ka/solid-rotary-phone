## 0. 已知条件与几何假设

**物性（附件1）**：
- 去离子水：ρ = 998.2 kg/m³，Cp = 4182 J/(kg·K)，k_f = 0.6 W/(m·K)，μ = 0.001003 kg/(m·s)
- 氮化铝（衬底/针肋）：k = 200 W/(m·K)
- 工况：ṁ = 1 g/s = 1×10⁻³ kg/s，T_in = 293 K，出口表压 0，体热源 5×10⁹ W/m³
- 散热区：L = 10 mm × 10 mm

**几何假设（热阻模型默认值）**：
| 符号 | 含义 | 数值 |
|---|---|---|
| N_ch | 并联微通道数 | 100 |
| w_ch | 通道宽度 | 0.08 mm |
| H_ch_ref | 微通道层参考深度（r=3.5 时） | 0.5 mm |
| H_tot | 总结构高度（近似固定） | H_ch_ref×(1+r_ref) = 2.25 mm |
| M | 歧管单元数（沿流向） | 4 |
| fin_per_row | 每排针肋根数 | 3 |
| δ_sub | 衬底厚度 | 0.2 mm |
| 针肋 | 圆柱形，d_pin=w·w_ch，高=H_ch | — |

## 1. 通用流动参数（以 w=0.2, r=3.5, n=4 为例）

**① 微通道深度**（总高近似固定，歧管加深→通道变浅）：
$$H_{ch}(r)=\frac{H_{tot}}{1+r}=\frac{2.25}{1+3.5}=0.500\ \text{mm}$$

**② 单通道流通截面积**：
$$A_c=w_{ch}\,H_{ch}=0.08\times0.50=0.04\ \text{mm}^2=4.0\times10^{-8}\ \text{m}^2$$

**③ 单通道质量流量**（流量均匀分配）：
$$\dot m_{ch}=\frac{\dot m}{N_{ch}}=\frac{1\times10^{-3}}{100}=1.0\times10^{-5}\ \text{kg/s}$$

**④ 通道平均流速**：
$$V=\frac{\dot m_{ch}}{\rho A_c}=\frac{1.0\times10^{-5}}{998.2\times4.0\times10^{-8}}=0.2505\ \text{m/s}$$

**⑤ 水力直径**：
$$D_h=\frac{2w_{ch}H_{ch}}{w_{ch}+H_{ch}}=\frac{2\times0.08\times0.50}{0.08+0.50}=0.1379\ \text{mm}=1.379\times10^{-4}\ \text{m}$$

**⑥ 雷诺数**（层流区）：
$$Re=\frac{\rho V D_h}{\mu}=\frac{998.2\times0.2505\times1.379\times10^{-4}}{0.001003}=34.4$$

**⑦ 针肋间隙流速**（绕流挤压）：
$$V_{gap}=\frac{V}{1-w}=\frac{0.2505}{1-0.2}=0.3131\ \text{m/s}$$

**⑧ 普朗特数**：
$$Pr=\frac{\mu C_p}{k_f}=\frac{0.001003\times4182}{0.6}=6.99$$

## 2. 热阻模型分步计算

### 2.1 对流换热系数

**① 通道壁面 Nu**（层流充分发展、等热流）：
$$Nu_{wall}=4.36\quad\Rightarrow\quad h_{wall}=\frac{Nu_{wall}\,k_f}{D_h}=\frac{4.36\times0.6}{1.379\times10^{-4}}=18966\ \text{W/(m²·K)}$$

**② 针肋直径**：
$$d_{pin}=w\,w_{ch}=0.2\times0.08=0.016\ \text{mm}=1.6\times10^{-5}\ \text{m}$$

**③ 针肋雷诺数**：
$$Re_d=\frac{\rho V_{gap} d_{pin}}{\mu}=\frac{998.2\times0.3131\times1.6\times10^{-5}}{0.001003}=5.0$$

**④ 针肋 Nu**（Zukauskas 单圆柱横掠，40<Re_d<4000 段）：
$$Nu_{pin}=0.683\,Re_d^{0.466}Pr^{0.37}=0.683\times5.0^{0.466}\times6.99^{0.37}=2.965$$

**⑤ 针肋对流系数**：
$$h_{pin}=\frac{Nu_{pin}\,k_f}{d_{pin}}=\frac{2.965\times0.6}{1.6\times10^{-5}}=111184\ \text{W/(m²·K)}$$

**⑥ 圆柱针肋效率**（m=√(4h/(k_fin·d))，mL=m·H）：
$$m=\sqrt{\frac{4h_{pin}}{k_{fin}d_{pin}}}=\sqrt{\frac{4\times111184}{200\times1.6\times10^{-5}}}=11789,\quad mL=11789\times0.0005=5.894$$
$$\eta_{fin}=\frac{\tanh(mL)}{mL}=\frac{\tanh(5.894)}{5.894}=0.1696$$

### 2.2 换热面积（每单元每通道 → 全系统）

**单元长度**：L_unit = L/M = 10/4 = 2.5 mm

**壁面面积（底壁+两侧壁，顶面不换热）**：
$$A_{wall,unit}=w_{ch}L_{unit}+2H_{ch}L_{unit}=0.08\times2.5+2\times0.5\times2.5=2.70\ \text{mm}^2$$
$$A_{wall}=N_{ch}M\,A_{wall,unit}=100\times4\times2.70=1080\ \text{mm}^2=10.8\ \text{cm}^2$$

**针肋面积**（含阻塞修正 exposure=1−0.5(w/0.3)⁸）：
$$A_{fin,unit}=n\,f_{pr}\,\pi d_{pin}H_{ch}\times f_{exp}=4\times3\times\pi\times0.016\times0.5\times0.998=0.296\ \text{mm}^2$$
$$A_{fin}=100\times4\times0.296=118\ \text{mm}^2=1.18\ \text{cm}^2$$

**总面积**：A_eff = A_wall + A_fin = 10.80 + 1.18 = **11.98 cm²** = 1.198×10⁻³ m²

**面积加权平均对流系数**：
$$h_{eff}=\frac{h_{wall}A_{wall}+\eta_{fin}h_{pin}A_{fin}}{A_{eff}}=\frac{18966\times10.8+0.1696\times111184\times1.18}{11.98}=18956\ \text{W/(m²·K)}$$

### 2.3 三项热阻

**① 导热热阻**：
$$R_{cond}=\frac{\delta_{sub}}{k_{AlN}A_{foot}}=\frac{0.2\times10^{-3}}{200\times(0.01)^2}=0.0100\ \text{K/W}$$

**② 对流热阻**：
$$R_{conv}=\frac{1}{h_{eff}A_{eff}}=\frac{1}{18956\times1.198\times10^{-3}}=0.0440\ \text{K/W}$$

**③ 流体升温热阻**（热容阻力）：
$$R_{fluid}=\frac{1}{2\dot m C_p}=\frac{1}{2\times1\times10^{-3}\times4182}=0.1196\ \text{K/W}$$

**④ 总热阻**：
$$R_{total}=R_{cond}+R_{conv}+R_{fluid}=0.0100+0.0440+0.1196=0.1736\ \text{K/W}$$

**⑤ 无量纲热阻 + 标定**：
$$R^*=R_{total}\dot m C_p=0.1736\times1\times10^{-3}\times4182=0.7259$$
$$R^*_{pred}=0.39612+0.47953\times0.7259=0.7442\quad(\text{数据 }0.7392)$$

> 基线（w=0,r=3,n=0）：R_total=0.1740 K/W，R*=0.7277→0.7451（数据 0.7408）
> 强化（w=0.2,r=3,n=10）：R_total=0.1654 K/W，R*=0.6915→0.7277（数据 0.7219）

## 3. 压降模型分步计算

### 3.1 沿程阻力（Darcy–Weisbach）

**摩擦因子**（层流）：
$$f=\frac{64}{Re}=\frac{64}{34.4}=1.862$$

**动压**：
$$\tfrac12\rho V^2=\tfrac12\times998.2\times0.2505^2=31.31\ \text{Pa}$$

**沿程压降**：
$$\Delta P_f=f\,\frac{L}{D_h}\,\tfrac12\rho V^2=1.862\times\frac{0.01}{1.379\times10^{-4}}\times31.31=4225\ \text{Pa}$$

### 3.2 针肋绕流形阻

**阻力系数**（圆柱横掠近似）：
$$C_D=1+\frac{10}{Re_d^{0.8}}=1+\frac{10}{5.0^{0.8}}=3.766$$

**迎风面积**：A_front = d_pin·H_ch = 0.016×0.5 = 8.0×10⁻⁹ m²

**针肋压降**（每条通道针肋数 = M·n·f_pr = 4×4×3 = 48）：
$$\Delta P_{pin}=\frac{(M\,n\,f_{pr})\,C_D\,\tfrac12\rho V_{gap}^2\,A_{front}}{A_c}=\frac{48\times3.766\times49.0\times8.0\times10^{-9}}{4.0\times10^{-8}}=1768\ \text{Pa}$$

### 3.3 歧管分配层

**歧管深度**：H_man = r·H_ch = 3.5×0.5 = 1.75 mm
**歧管流通面积**：A_man = W_man·H_man = 0.3×1.75 = 0.525 mm²（W_man=0.3mm 为分配槽宽）
**歧管流速**：
$$V_{man}=\frac{\dot m}{\rho A_{man}}=\frac{1\times10^{-3}}{998.2\times0.525\times10^{-6}}=1.908\ \text{m/s}$$

**歧管压降**（摩擦+动压）：
$$\Delta P_{man}=\left(f_{man}\frac{L_{man}}{D_{man}}+1\right)\tfrac12\rho V_{man}^2=2284\ \text{Pa}$$

### 3.4 转弯/进出口局部损失

$$\Delta P_{turn}=K_{turn}\,\tfrac12\rho V^2=1\times31.31=31.3\ \text{Pa}$$

### 3.5 总压降与标定

$$\Delta P_{total}=4225+1768+2284+31=8309\ \text{Pa}$$

标定（最小二乘，分量权重）：P\*_pred = 0.1115（数据 0.1068）
- 标定后分量贡献：歧管 52.7%、针肋 26.4%、沿程 20.9%、转弯 0%

> 基线（w=0,r=3,n=0）：ΔP=7302 Pa（dP_pin=0），P*_pred=0.1115（数据 0.1240）
> 强化（w=0.2,r=3,n=10）：ΔP=11723 Pa（dP_pin=4421），P*_pred=0.1660（数据 0.1511）

## 4. 温度非均匀性模型分步计算

**分配不均匀数**（歧管动压/通道压降）：
$$x_{mal}=\frac{\tfrac12\rho V_{man}^2}{\Delta P_f+\Delta P_{pin}}=\frac{1817}{4225+1768}=0.3032$$

**局部强化特征**：
$$x_w=(w-0.2)^2=(0.2-0.2)^2=0,\qquad x_n=(n-4)^2=(4-4)^2=0$$
$$n_{lin}=n=4,\qquad x_{r2}=(r-3.5)^2=(3.5-3.5)^2=0$$

**无量纲非均匀性（标定后）**：
$$U^*=0.7427+0.1012\,x_{mal}+1.524\,x_w+0.0002\,x_n+0.0045\,n+0.015\,x_{r2}$$
$$=0.7427+0.1012\times0.3032+0.0045\times4=0.7914\quad(\text{数据 }0.7751)$$

> 基线（w=0,r=3,n=0）：x_mal=0.585，U*=0.8699（数据 0.8731）
> 强化（w=0.2,r=3,n=10）：x_mal=0.286，U*=0.8276（数据 0.8278）
