# 第四问总结：权重敏感性分析 + 鲁棒设计方案

> 代码：`run_q4.py`（权重扫描/后悔/膝点）、`plot_q4.py`（可视化）
> 方法：权重空间**网格采样**（单纯形 1326 点）；鲁棒判据用**方法2 Minimax Regret + 方法4 膝点(最小距离法)**

## 1. 场景权重（参考思路 A 部分）

| 场景 | (α_R, β_P, γ_U) |
|---|---|
| 高性能（AI/HPC） | (0.6, 0.2, 0.2) |
| 节能（移动/低功耗） | (0.2, 0.6, 0.2) |
| 可靠性（航天/工业） | (0.2, 0.2, 0.6) |
| 均衡 | (1/3, 1/3, 1/3) |

## 2. 权重敏感性分析（B 部分）

- 权重单纯形网格采样（步长 0.02，**1326 个权重点**）；
- 每组权重用加权和（min-max 归一化）从 Pareto 前沿选最优；
- **最优方案频次 Top**：
  | (w, r, n) | 频次占比 |
  |---|---|
  | (0.220, 4.500, 4) | **31.2%** |
  | (0.215, 4.500, 4) | 14.6% |
  | (0.210, 4.500, 4) | 6.7% |
  | (0.225, 4.500, 2) | 6.6% |

  → w≈0.21~0.23、r=4.5、n=4 的设计族占据权重空间的最大份额（分区图见 `q4_weight_simplex.png`）。

## 3. 鲁棒设计判据（C 部分，按用户选择方法2+方法4）

**方法2：Minimax Regret**
    x* = argmin_x max_w [F_w(x) − F_w(x*(w))]
- 结果：**(0.225, 4.500, 6)**，最坏后悔 = 0.3754（Top5 均为 w≈0.215~0.235、r=4.5、n=6）

**方法4：膝点（最小距离法，距归一化理想点(0,0,0)最近）**
- 结果：**(0.225, 4.500, 4)**，距理想点 = 0.5320

两种方法都指向 **w=0.225、r=4.5** 同一区域（n 差一档：4 vs 6）。

## 4. 推荐鲁棒方案与优势论证（D 部分）

**推荐：膝点方案 (w*, r*, n*) = (0.225, 4.500, 4)**
- R = 0.7412，P = 0.0853，U = 0.7719

**理由**：
1. 与最高频设计 (0.220,4.5,4)、Q3 熵权-TOPSIS (0.215,4.5,4) **完全一致/极接近**；
2. 4 场景性能损失最小（见下表）：对"专属最优"的损失仅 0.0007~0.0147；
3. minimax regret 也指向同一 w/r 区域（n=6 仅最坏后悔略低，但场景损失明显更大）→ 膝点方案是"多准则一致 + 场景损失最小"的鲁棒解。

**场景性能损失（相对各场景专属最优）**：
| 场景 | 膝点鲁棒损失 | minimax鲁棒损失 |
|---|---|---|
| 高性能 | 0.0147 | 0.0182 |
| 节能 | 0.0057 | 0.1392 |
| 可靠性 | 0.0007 | 0.2210 |
| 均衡 | 0.0015 | 0.1206 |

→ 膝点鲁棒方案在各场景下均接近最优，性能损失可控（见雷达图 `q4_radar.png`、损失对比 `q4_scenario_loss.png`）。

## 5. 与 Q1/Q3 的呼应

- 鲁棒方案 w≈0.22、n=4 与 Q1"w≈0.2、n≈4 时 R/U 最优"、Q3 最优 (0.215,4.5,4) 一致；
- r=4.5（上限）对应 P、U 偏好，符合"偏好变化下仍稳定"的定位。
