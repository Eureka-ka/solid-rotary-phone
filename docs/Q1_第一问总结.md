# 第一问总结：芯片歧管式微通道热管理系统机理建模

> 对应代码：`code/thermal_resistance_model.py`、`code/pressure_drop_model.py`、`code/nonuniformity_model.py`
> 对应主程序：`run_thermal_resistance.py`、`run_pressure_drop.py`、`run_nonuniformity.py`
> 数据：附件2（84 组样本）；验证指标均为"标定后"结果。

## 1. 问题与建模框架

第一问要求：建立关键结构参数（针肋宽度比 w、歧管深高比 r、针肋排数 n）与三项性能指标
（无量纲热阻 R、无量纲压降 P、无量纲温度非均匀性 U）之间关系的机理数学模型，分析影响规律，
并论证三项指标作为综合评价依据的合理性。

建模路线（机理 + 数据标定）：
1. 用传热/流动基本机理建立 (w,r,n) → (R,P,U) 的解析模型（函数形式来自物理）；
2. 由于结构图未给全几何尺寸、无量纲参考归一化未显式给定，模型中的待定常数由附件2
   84 组样本最小二乘标定（标定只调量级/归一化，不改变机理趋势）；
3. 用标定后模型与附件2 数据做趋势互验，验证机理规律。

## 2. 三个机理模型

### 2.1 热阻模型（串联热阻分解）

    R_total = R_cond + R_conv + R_fluid
- R_cond = δ_sub/(k_AlN·A_foot) ≈ 0.010 K/W（衬底导热，结构无关）
- R_conv = 1/(h_eff·A_eff)（对流，w/r/n 作用主战场）
  · 壁面 Nu=4.36（层流等热流）/ Gnielinski；针肋 Nu 用 Zukauskas 单圆柱横掠关联式
  · 圆柱针肋效率 η=tanh(mH)/(mH)；h_eff 按面积加权
  · 针肋阻塞/尾流修正 A_fin_eff = A_fin·[1−0.5·(w/0.3)⁸]
- R_fluid = 1/(2ṁCp) ≈ 0.120 K/W（冷却液线性升温的热容阻力，结构无关下限）
- 无量纲：R* = R_total·ṁ·Cp；标定 R*_pred = 0.39612 + 0.47953·R*
- 验证：R²=0.7333，Pearson=0.8564，平均相对误差 0.58%

关键机理结论：R_cond + R_fluid 构成"结构无关热阻底座"，解释了附件2 中 R 仅在 0.72~0.77
窄带内变化（约 7%）——结构参数只能调节 R_conv 部分，热阻优化空间天然受限。

### 2.2 压降模型（多段串联）

    ΔP = ΔP_manifold + ΔP_channel + ΔP_pin + ΔP_turn
- 沿程：ΔP_f = f·(L/D_h)·(ρV²/2)，f=64/Re（层流）/ Blasius
- 针肋：ΔP_pin = (M·n·fin_per_row)·C_D·(ρV_gap²/2)·(d_pin·H)/A_c，C_D=1+10/Re_d^0.8
- 歧管：ΔP_man = (f_man·L_man/D_man+1)·(ρV_man²/2)，V_man=ṁ/(ρ·W_man·H_man)，H_man=r·H_ch
- 转弯：ΔP_turn = K_turn·(ρV²/2)
- 标定：P*_pred = c0 + c_f·ΔP_f + c_pin·ΔP_pin + c_man·ΔP_man + c_turn·ΔP_turn
- 验证：R²=0.8853，Pearson=0.8801，平均相对误差 6.54%
- 标定后分量贡献：歧管 52.7%、针肋 26.4%、沿程 20.9%、转弯 0%

关键机理结论：歧管压降占主导 → P 随 r 增大而下降（歧管越深、V_man 越小）；针肋与沿程
分量使 P 随 w、n 增大而上升。

### 2.3 温度非均匀性模型（分配均匀性 + 局部强化均匀性）

    U* = c0 + c1·x_mal + c2·x_w + c3·x_n + c4·n + c5·(r−r_opt)²
- x_mal = (ρV_man²/2)/(ΔP_f + ΔP_pin)：分配不均匀数（歧管动压/通道压降）
  · r 越大 → V_man 越小 → 分配越均匀 → U 越小；w、n 越大 → 通道压降越大 → 分配改善
- x_w=(w−0.2)²、x_n=(n−4)²：局部强化非均匀（针肋过稀/过密都有热点）
- c4·n：排数线性驱动的局部扰动/分配不均；c5·(r−3.5)²：歧管最优深度
- 验证：R²=0.7594，平均相对误差 0.95%；模型 U* 范围 0.784~0.871（数据 0.774~0.873）

关键机理结论：U 的非单调性来自"分配均匀化收益"与"局部强化扰动"的权衡——
w≈0.2、n≈4、r≈3.5~4 附近 U 取极小。

## 3. 影响规律与数据互验总表

|---|---|---|---|---|

- r：R +0.54，P −0.62，U −0.22
- n：R −0.50，P +0.43，U +0.30
- 指标间：R–P −0.68（强冲突）、P–U +0.47、R–U −0.08（近独立）

## 4. 三项指标作为综合评价依据的合理性论证

**（1）工程维度互补**
- 热阻 R：直接决定芯片结温，代表**散热能力**与性能稳定性；
- 压降 P：决定冷却液泵功与系统能耗（泵功 ∝ ΔP·ṁ/ρ），代表**运行成本**；
- 温度非均匀性 U：与热点、热应力、热疲劳及界面失效直接相关，代表**可靠性与寿命**。
三项指标分别覆盖"效率—成本—可靠性"，工程意义完整互补。

**（2）统计维度不可替代**
- R 与 U 几乎不相关（−0.08）：二者刻画不同物理过程，不能用热阻代替均匀性；
- R 与 P 强冲突（−0.68）：降低热阻（强化流动）必然以压降上升为代价，说明必须权衡；
- P 与 U 正相关（+0.47）：高压降往往伴随流量分配不均。
三者构成近似正交的"效率—成本—可靠性"评价体系，缺一不可。

**（3）无量纲形式的优势**
- R、P、U 均为无量纲量，与具体尺寸/工况解耦，可跨设计、跨尺度直接比较；
- 天然适合作为统一优化目标（Q3 多目标优化），也便于 Q2 建立代理模型。

## 5. 模型假设与标定说明

- 几何（热阻模型）：N_ch=100、w_ch=0.08mm、H_ch(r)=H_tot/(1+r)、M=4、fin_per_row=3、
  δ_sub=0.2mm；针肋圆柱形 d_pin=w·w_ch、高=H_ch；换热面=底壁+两侧壁。
- 压降/非均匀性模型：H_ch 取固定值 0.5mm，r 只改变歧管层 H_man=r·H_ch（使 P 随 r 下降）；
  W_man=0.3mm 为歧管分配槽宽（歧管压降占主导）。
- 流动：稳态、流量均匀分配、Re≈31~110（层流/过渡）、物性定值。
- 标定：机理模型函数形式来自物理；待定常数（仿射系数/分量权重/最优 w、n、r）由附件2
  84 组样本最小二乘标定；标定不改变机理趋势。
- 已知差异与局限：
  ① 热阻模型与压降模型对 H_ch 与 r 的关系假设不同（热阻：总高度固定、H_ch 变浅；
     压降：H_ch 固定、H_man=r·H_ch），论文中需分别说明或后续统一；
  ② 结构A/结构C 的取舍见 PROGRESS.md（当前采用回退后版本，N_ch=100、M=4）；
  ③ U 模型为半经验形式（二次项刻画非单调），R²=0.76 低于 R/P，属数据本身噪声较大。

## 6. 结论

- 建立了 (w,r,n)→(R,P,U) 的机理模型：热阻（串联分解）、压降（多段串联）、
  温度非均匀性（分配均匀性+局部强化），三条趋势均与附件2 数据互验一致。
- 影响规律：R 随 w 先降后微升（w≈0.2 最小）、随 r 递增、随 n 递减；
  P 随 w、n 递增、随 r 递减；U 随 w、n 先降后升（w≈0.2、n≈4 最小）、随 r 先降后微升。
- 三项指标覆盖"效率—成本—可靠性"且近似正交，作为综合评价依据合理。
- 机理模型为 Q2 代理模型提供物理先验（趋势方向、函数形式），Q3 优化以 Q2 精确映射为基础。
